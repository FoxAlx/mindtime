# Mindtime

Meditation timer for Android and iOS.

## Repository structure

- `android/` — native Android app, written in Kotlin.
- `ios/` — native iOS app, written in Swift.

The apps are maintained as separate native projects. Platform-specific source
code and build configuration belong in their respective directories. Shared
product documentation and repository-level tooling belong at the root.

See the platform README files for the intended project locations:

- [Android](android/README.md)
- [iOS](ios/README.md)
